# Python Basics 🐍

This repository contains my Python learning journey from the fundamentals to core programming concepts. I use these Jupyter Notebooks to explore concepts, write clean examples, and practice problem-solving hands-on.

---

## 📚 Topics Covered

### 1. Python Foundations
* **Introduction & Syntax:** Basic syntax, print formatting, script execution.
* **Variables:** Dynamic assignment, naming rules, and memory references.
* **Data Types:** `int`, `float`, `str`, `bool`, along with type inspection (`type()`) and type casting.
* **Keywords & Operators:** Python reserved keywords, arithmetic, comparison, logical, and assignment operators.

### 2. Built-in Data Structures
* **Lists:** Creation, indexing, slicing, item assignment, and built-in methods (`append`, `extend`, `pop`, `sort`).
* **Tuples:** Immutability, tuple packing, tuple unpacking, and indexing.
* **Sets:** Unordered unique collections, adding/removing items, union, intersection, and difference operations.
* **Dictionaries:** Key-value pairs, accessing keys safely, dictionary mutation, and key methods (`keys()`, `values()`, `items()`, `get()`).

### 3. Control Flow & Modular Logic
* **Conditional Statements:** `if`, `if-else`, `if-elif-else`, and nested conditions.
* **Looping Statements:** `for` loop traversal over strings, lists, ranges, and sequences.
* **Functions:** Modular code design with `def`, positional and keyword arguments, default parameters, local vs. global scope, and the `return` statement.
