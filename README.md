## 📚 Topics Breakdown

<details open>
<summary><b>1. Core Foundations</b></summary>

* **Introduction & Basics:** Python syntax, comments, execution flow, running scripts.
* **Variables:** Dynamic typing, naming conventions (PEP 8), memory assignment.
* **Data Types:** `int`, `float`, `str`, `bool`, type checking with `type()`, and type casting.
* **Keywords & Operators:** Reserved words, arithmetic, comparison, logical, and assignment operations.
</details>

<details open>
<summary><b>2. Data Structures</b></summary>

* **Lists:** Mutable sequences, indexing, slicing, appending, inserting, popping, and built-in list methods.
* **Tuples:** Immutable sequences, element packing/unpacking, performance trade-offs.
* **Sets:** Unordered unique collections, set arithmetic (unions, intersections, differences).
* **Dictionaries:** Key-value pairs, nested dictionaries, `.get()`, `.keys()`, `.values()`, `.items()`.
</details>

<details open>
<summary><b>3. Logic, Control Flow & Modular Code</b></summary>

* **Conditional Logic:** `if`, `elif`, `else`, boolean chaining, nested decisions.
* **Looping Structures:** `for` loops, sequence iteration, `range()`, nested iteration.
* **Functions & Scope:** Modular design with `def`, positional vs. keyword arguments, default parameters, `return` values vs. `None`, local vs. global scope.
</details>
